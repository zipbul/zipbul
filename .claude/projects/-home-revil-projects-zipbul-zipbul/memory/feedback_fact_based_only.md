---
name: 사실 기반으로만 말할 것
description: 코드베이스를 확인하지 않은 추측을 사실처럼 말하지 말 것
type: feedback
---

코드베이스를 직접 확인하지 않은 내용을 문제점이나 사실로 제시하지 말 것.

**Why:** 추측으로 존재하지 않는 문제를 만들어내면 잘못된 설계 결정으로 이어진다. 실제로는 기존 메커니즘으로 해결 가능한 것을 새 인터페이스가 필요하다고 주장하는 등의 오류가 발생했다.

**How to apply:** 주장하기 전에 반드시 코드를 읽어서 확인한다. 확인하지 않았으면 "확인하지 않았다"고 명시한다. 추측과 사실을 절대 섞지 않는다.
